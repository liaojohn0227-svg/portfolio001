# 照片放這裡

把照片放進這個資料夾，再到 HTML 裡把對應的 `<!-- <img ...> -->` 註解拿掉（刪掉前後的 `<!--` 和 `-->`）就會顯示。

## 檔名對照

| 檔名 | 用在哪裡 | 建議比例 |
|---|---|---|
| `hero.jpg` | 首頁主視覺 | 3:2 橫式 |
| `p01-cover.jpg` | 首頁作品 01 | 3:2 橫式 |
| `p02-cover.jpg` | 首頁作品 02 | 4:5 直式 |
| `p03-cover.jpg` | 首頁作品 03 | 3:4 直式 |
| `p04-cover.jpg` | 首頁作品 04 | 16:9 橫式 |
| `me.jpg` | 關於我的照片 | 3:4 直式 |
| `p01-lead.jpg` | 作品 01 內頁主圖 | 16:9 橫式 |
| `p01-1.jpg` ～ `p01-6.jpg` | 作品 01 內頁的六張圖 | 依序 3:2、4:5、3:4、21:9、1:1、3:4 |

作品 02～04 依此類推（`p02-lead.jpg`、`p02-1.jpg`…）。

比例不同也沒關係，網頁會自動裁切置中；但比例接近的話，構圖會比較完整。

## 檔案大小

- 長邊 2000–2400 px 就夠了，不需要原始尺寸。
- 每張盡量壓在 500 KB 以下（可用 squoosh.app 免費壓縮）。
- 檔名只用小寫英文、數字和 `-`，**不要有空格或中文**。GitHub Pages 會分大小寫，`Hero.JPG` 和 `hero.jpg` 是不同檔案。
